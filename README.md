# Car Price Prediction System

A machine learning web application that predicts the selling price of a car based on its specifications and details.

The project uses a trained machine learning model for prediction, FastAPI for the backend API, and Streamlit for the user interface.

## Features

- Predict car selling prices using a trained machine learning model
- FastAPI backend for handling prediction requests
- Streamlit web interface for user interaction
- Input validation using Pydantic
- Support for different fuel types, seller types, and transmissions
- Simple and easy-to-use interface

## Technologies Used

- Python
- Machine Learning
- Scikit-learn
- FastAPI
- Streamlit
- Pydantic
- Requests
- Pickle
